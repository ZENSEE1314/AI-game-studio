# Gameplay Specification

Current prototype: choose a creature, begin, use Resonate until victory or defeat, then restart. Captured species appear once in a local collection.

Planned mobile loop: visit a safe habitat or stationary exploration scene, discover an encounter, choose an action, befriend a creature, resolve a short quest and save progress. Target a complete introductory session without location permission.

Progression: habitat completion flags unlock chapters; companion discovery fills a journal. No energy timer prevents essential access. Tuning must be data-driven and versioned.

Acceptance: a new player understands the encounter within one tutorial; a lost connection never destroys an already-acknowledged reward; the game remains navigable with reduced motion and larger text. These are future release gates, not current measured results.
