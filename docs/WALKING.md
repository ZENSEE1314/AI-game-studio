# Walking Plan

Walking is proposed, not implemented. The browser demo collects no location or motion data.

Build a complete stationary exploration mode first. For optional walking, request permission only when the player chooses it, explain its purpose, and offer an equivalent path when denied. Test foreground sessions before considering background collection. Decide whether device step totals suffice before collecting coordinates.

Do not place mandatory objectives in roads, restricted areas or unsafe locations. Pause movement-based interactions at unsuitable speeds. Avoid incentives for nighttime visits. Handle denied permission, stale sensors, app suspension, duplicate samples and offline sessions. A production privacy review must establish retention and deletion behavior before launch.
