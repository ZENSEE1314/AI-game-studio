# Website Plan

Current website is the working Form & Fable studio. It is served locally and can be compiled to a static `dist/` folder. No production URL has been deployed.

Planned public game site: hero with the actual gameplay promise, playable demo, creature gallery, development journal, accessibility information, support and privacy pages. Include no invented launch date, reviews, active-player counts or store badges.

A future waitlist needs an actual server-backed submission, validation, abuse protection, clear consent and deletion behavior. Do not show a fake success state for a client-only form. Keep studio access private once cloud collaboration exists.

Deployment checklist: choose host and domain, configure HTTPS and caching, validate routing and assets under the intended base path, test mobile layouts, confirm analytics choice, and document rollback. Hosting has not been selected or purchased.
