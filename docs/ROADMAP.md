# Roadmap

## v0.1 — Studio foundation (this increment)

Responsive overview, local persistence, creature editing/search/export, Markdown bibles, production board, motion briefs, playable encounter and collection. Foundation documentation and CI.

## v0.2 — Reliable content workspace

Versioned backup import with preview and validation, document revision history, creature asset uploads, schema-aware content checks and modular UI components. Add automated end-to-end tests for core flows.

## v0.3 — AI drafting and collaboration

Choose provider and budget; implement authenticated project API, memberships, server-only secrets, metered generation jobs, schema validation, review queue and cloud saves. No automatic publishing from generated drafts.

## v0.4 — Mobile vertical slice

Confirm engine and art style. One habitat, one quest, three finished creatures, native device builds, accessible stationary alternative and a migration path. Optional walking remains separately gated.

## Release candidate

Production authority, privacy/retention decisions, device profiling, accessibility and store checks, restore/recovery tests, feedback fixes and support workflow. Milestones are exit criteria, not promised dates.
