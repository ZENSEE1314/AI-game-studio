# Economy Plan

No currency, purchasing or trading is implemented in v0.1. The only reward is a unique creature collection entry after victory.

Proposed soft progression uses discovery journal entries and habitat restoration milestones. Start with no paid random rewards. If cosmetics are introduced, separate cosmetic ownership from gameplay power and verify purchases on the server.

Every future reward definition must name its source, cap, repeatability, sink if any, and abuse case. Reward issuance uses an idempotent ledger; balances are derived from trusted events. Track distribution and completion rates before setting grind requirements. Never introduce token trading or financial claims without a separate explicit product decision.
