# QA Gates

## Current local app

- Build TypeScript and production bundle.
- Lint source; validate seed creature schema.
- Create/edit a creature; reload and verify persistence.
- Search by name and element; display an empty result.
- Edit each Markdown document; download and check content.
- Add a production task, edit owner, move status.
- Complete a battle; clamp HP, award once, disable action on finish.
- Defeat and restart; ensure no victory reward on defeat.
- Verify keyboard navigation, modal dismissal, reduced motion and narrow layouts.

## Before cloud release

Authentication and per-project authorization, request validation, conflict handling, backup restore, idempotent rewards, rate limits, generation budget caps, secret scanning and error visibility.

## Before native release

Device matrix, frame/memory measurements, offline behavior, permission denials, accessibility, signing recovery, store requirements and support contact. Passing local prototype checks does not imply native-release readiness.
