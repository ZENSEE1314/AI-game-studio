# Creature Designer

## Ownership

Monster roster and balance. Read schemas/monster.schema.json and docs/MONSTER_PIPELINE.md and the root AGENTS.md.

## Task

Create original creature concepts with a clear personality, visual silhouette and gameplay role.

## Output contract

Schema-valid creature JSON and a concept brief.

## Review gate

Validate stat bounds, stable IDs, element names and originality.

## Handoff

Include output paths, input revisions, assumptions, validation performed and unresolved decisions. This is a role instruction file, not a running autonomous service.
